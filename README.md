# Motion Planning Simulator

This repository is configured for C++ development using raylib.

## Setup

1. Install raylib with Homebrew:
   `brew install raylib`
2. Build the sample app:
   `make`
3. Run it:
   `./motion-planning-simulator`

The project uses `pkg-config` to locate the raylib headers and libraries, so it works with the Homebrew installation on macOS.
